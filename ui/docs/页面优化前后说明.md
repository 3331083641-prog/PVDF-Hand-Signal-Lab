# 页面优化前后说明

## 浏览器审查基线

重构前已在 1440×900 视口实际打开首页、认识装置、PVDF机理、交互实验室、实时映射和手势任务。审查发现共同问题是字体偏小、页面松散、静态图片权重过高、操作与反馈脱节、卡片承担过多结构职责。

| 页面 | 优化前 | 优化后 |
|---|---|---|
| 首页 | 宣传式图文首屏，小指标与路径分散焦点 | 紧凑教学总控首屏，模式切换、可点击装置标签与五步导航形成入口 |
| 认识装置 | 热点与右侧文字并列，点击缺少空间反馈 | 大图聚焦、放大镜弱化、关节/装置组成双层浏览、顺序与自动讲解 |
| PVDF机理 | 静态图片与滑块并置，参数不驱动图像 | 曲率、电极、电荷、极性、受力与输出波形同步变化 |
| 交互实验室 | 顶部静态流程图抢占空间，实验主次不清 | 简洁四步导航，参数—主图—对照—结论构成单一实验工作区 |
| 实时映射 | 概念图与小型虚拟手并列，主交互不突出 | 左侧大虚拟手主舞台，右侧关节、姿态、预设和播放控制 |
| 手势任务 | 静态手势海报作为核心 | 左侧动作选择、中部动态手、右侧六步任务和即时反馈 |

## 全站变化

- 首页主标题增至 48–76px，页面标题增至 36–56px，正文为 17–19px。
- 所有核心按钮和任务按钮达到至少 44px 触控高度。
- 主要结构从“卡片列表”改为舞台、侧栏、控制区、结果区和结论区。
- 静态流程图与手势海报退出核心操作区，但继续保留在图片资产文档中作为概念说明素材。
- 移除独立“竞赛亮点”页面。
