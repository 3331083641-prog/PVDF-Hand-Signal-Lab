# COM8 实时串口接入说明

## 已实现的数据链

`USB-SERIAL CH340K (COM8)` → Web Serial → 31 字段帧解析 → 28 路原始电压 → 14 路差分 → 二阶 6 Hz 低通 → SIA 梯形积分 → 14 关节角与 Pitch/Yaw/Roll → 三维手。

- 串口：COM8（由浏览器端口选择器确认）
- 波特率：460800
- 帧格式：一行 31 个逗号分隔数值
- 字段 1–28：14 对 PVDF 原始电压
- 字段 29–31：Pitch、Yaw、Roll，单位为弧度
- 目标采样率：80 Hz
- 差分：`Udiff = (V+ - V−) / 2`
- 小信号积分阈值：0.006 V
- 保持时间修正：`1.056 - 0.11 × exp(-t / 2.3374)`

## 现场使用

1. 使用最新版桌面 Chrome 或 Edge 打开页面；Safari、Firefox 当前不支持 Web Serial。
2. 进入“信号与映射实验台”，点击右侧“实时串口”。
3. 在系统端口选择器中选择“USB-SERIAL CH340K (COM8)”。
4. 保持手部静止 2 秒，等待零点校准完成。
5. 选择关节，观察 V+/V−、差分信号、角度及三维手同步变化。

浏览器出于安全要求，首次连接必须由用户点击并选择端口，网页不能静默占用 COM8。COM8 同一时间只能被一个程序打开，连接网页前应关闭占用该端口的 Python 上位机或串口监视器。

## 角度标定边界

现有上位机配置中的 14 个 `angle_gain` 均为 0，说明尚未保存实测 0°→90° 标定常数。网页在未标定关节上使用明确标记的教学增益，以便先验证映射链路；正式实验前应逐关节执行：

1. 手指回到 0°并点击“角度归零”；
2. 点击“开始 0→90°”；
3. 将当前关节连续弯曲到 90°；
4. 点击“完成 90°”。

标定结果保存在当前浏览器的 `localStorage` 中，不会覆盖桌面上位机的 JSON 配置。
