## shape

- 将原六页分散结构重塑为四页连续教学路径：首页、认识装置、PVDF 机理、关节信号与动作映射实验台。

- 环绕观察使用阻尼；点击关节后才触发聚焦。
- 复杂动效响应 `prefers-reduced-motion`。
