# PVDF 动态电荷动画说明

## 教学目标

动画用于回答一个明确问题：双层 PVDF 在关节弯曲时，为什么会得到方向相反的两路原始响应，并经差分形成更清晰的有效信号。

它表达的主链路是：

`机械弯曲 → 上下层相反应力 → 电位移变化 → 电极自由电荷重新分布 → V+ / V− 反向响应 → Udiff`。

## 结构模型

主视图以可变曲率的七层剖面绘制：

1. 上层 PI/Copper FPC；
2. 上层导电胶带；
3. 上层 PVDF；
4. 中间绝缘层；
5. 下层 PVDF；
6. 下层导电胶带；
7. 下层 Copper/PI FPC。

七层厚度为可视化放大，不代表真实厚度比例。PVDF 层内部的小箭头表示已有极化偶极的平均方向；红蓝粒子只布置在 PVDF/电极界面附近，表示电极自由电荷的动态重新分布，不在 PVDF 本体或绝缘层中穿行。

## 状态机与动画规则

| 状态 | 进入条件 | 几何 | 应力 | 电荷/极化 | 波形 |
|---|---|---|---|---|---|
| 静止 | 目标角与当前角稳定在零附近 | 平直 | 很弱 | 极化箭头保留，界面电荷低透明度 | Udiff≈0 |
| 弯曲 | 角度绝对值增加 | 曲率随 `physicalAngle` 增加 | 正向时上拉伸/下压缩；反向交换 | 密度随 `|Udiff|`、速度与应力增加 | 默认极化下正向为正脉冲 |
| 保持 | 角度达到目标且保持 | 曲率不恢复 | 静态应变仍存在 | 动态电荷指示随终端响应衰减，极化箭头不消失 | 逐渐回到 0 V |
| 释放 | 角度绝对值减小 | 曲率向零回落 | 应力变化方向反转 | 界面符号相对进入弯曲时反转 | 反向脉冲 |

“弯曲方向”改变几何与应力方向；“极化方向”只改变电荷符号和输出符号。因此同一几何动作在极化翻转后，`Udiff` 会反号。

## 与信号引擎的统一

PVDF 页不单独绘制一条装饰波形，而是直接复用实验台的教学推演：

- 采样率：80 Hz。
- 原始通道：`V+ = 1.65 + motion + common + n+`；`V− = 1.65 − motion + common + n−`。
- 差分：`Udiff = (V+ − V−) / 2`。
- 静止阶段只有小幅可复现噪声；弯曲/伸展产生不规则瞬态；保持时端口响应衰减。
- 粒子密度、界面符号和差分曲线均由同一时刻的 `Udiff` 与运动阶段驱动。

页面默认只显示差分有效信号。点击“查看原理”可展开 `V+`、`V−` 当前值与公式，避免主界面堆叠三张曲线。

## 参数联动

- 弯曲角度：改变目标曲率与单次信号面积。
- 动作速度：改变瞬态峰值与持续时间，不改变目标几何角度。
- 保持时间：几何保持不变，动态端口信号继续衰减。
- 弯曲方向：同时反转上下层拉伸/压缩和输出符号。
- 极化方向：反转界面电荷和波形符号，保持几何不变。
- 复位：回到平直、静止和默认极化状态。
- 播放完整周期：依次执行弯曲、保持、释放，便于课堂演示。
