# 页面重构说明

## 结构变化

最终导航只保留：首页、认识装置、PVDF 机理、关节信号与动作映射实验台。手势任务、独立实时映射、竞赛亮点、总结页和固定页脚均已移除。

学习路径被收束为：认识真实装置 → 理解双层 PVDF → 选择关节 → 观察双通道 → 观察差分 → 积分得到角度 → 同步驱动三维手。

## 四页职责

- 首页：一屏说明装置、材料、信号和映射关系，只保留“开始学习”和“直接进入实验”两个主要入口。
- 认识装置：单一三维舞台；支持环绕、缩放、复位、14 关节点选、器件点选、自动讲解和点击附近浮框。
- PVDF 机理：双层 `PI/Copper—导电层—PVDF—绝缘层—PVDF—导电层—Copper/PI` 动态剖面；弯曲、速度、方向和极性共同驱动电荷与差分信号。
- 实验台：左侧单图波形，中间统一三维手，右侧关节/姿态/动作控制；把原交互实验室和实时映射合并到同一视口。

## 交互与视觉原则

- 用户先操作，说明在对象附近出现；不再永久占用大侧栏。
- 数据与模型同步：选择关节会同时改变波形来源、角度结果和三维高亮。
- 白、暖灰、冷灰构成精密仪器环境；深蓝承担结构，橙黄对应 FPC/有效信号，青色只用于数据提示。
- 卡片仅用于真正独立的信息单元；主要页面以舞台、控制轨和测量区组织。
- 全站支持键盘焦点、文字替代、`aria-pressed`、`prefers-reduced-motion` 和 WebGL 失败回退。

## 模拟与真实数据边界

波形使用论文约束下的固定种子教学推演，不从静态图片截取，也不宣称为实测。实时串口入口保留为待接入状态；未连接时不会用模拟数据冒充串口数据。
