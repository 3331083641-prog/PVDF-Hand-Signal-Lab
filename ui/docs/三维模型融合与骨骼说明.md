# 三维模型融合与骨骼说明

## 资产审计

| 资产 | 实际结果 | 采用方式 |
| --- | --- | --- |
| `三种手势手掌1.blend` | 1 个永久姿态手网格、1 个 Armature、16 根骨骼、3316 三角面、无 Action | 保留骨骼拓扑与比例；依据静止骨骼复刻中立张开手 |
| `Hitem3d-1784084384679(1).fbx` | 1 个无骨骼高密度装置网格、1,990,094 三角面 | 提取手背电路主体并减面；指部 FPC 按骨骼重建 |
| 第二个 Blend | 未找到 | 未采用，也未伪造 |

处理使用 Blender 5.1.2。较低版本会提示源文件由更新版本写入并可能丢失数据，因此最终资产全部由 5.1.2 重新读取、融合和导出。

## 融合流程

脚本：`tools/blender/merge_rig_optimize_hsad.py`。

1. 打开 Blend，清除姿态变换并将中文骨骼名映射为稳定英文节点名。
2. 以静止骨骼坐标为基准统一单位、轴向和尺度。
3. 因源网格已固化在两指动作，使用平滑重叠节段重建中立金黄色手，不把源姿态网格当作完整手。
4. 导入 FBX，使用主成分轴校正方向并进行网页减面。
5. 保留手背电路主体；删除会跨指错位的扫描支路。
6. 依据 14 根关节骨骼重新创建柔性 FPC 检测片，各节点随对应骨骼运动；手背电路绑定 `WristRoot`。
7. 添加 ESP32、电池、电源管理和信号调理点击代理；代理在网页中不可见但可被 Raycaster 选择。
8. 保留对象、骨骼、材质和节点名，以 Draco 压缩导出 GLB。

## 节点与骨骼

根与装置节点：`HandRoot`、`WristRoot`、`HandMesh`、`MainFPC`、`DeviceRoot`、`CircuitModule`、`ESP32Module`、`BatteryModule`、`PowerManagement`、`SensorGroup`。

| UI | 骨骼 | 原始通道 | 有效通道 |
| --- | --- | --- | --- |
| T2 | Thumb_IP | CH1 / CH2 | D1 |
| T1 | Thumb_MCP | CH3 / CH4 | D2 |
| I3 | Index_DIP | CH5 / CH6 | D3 |
| I2 | Index_PIP | CH7 / CH8 | D4 |
| I1 | Index_MCP | CH9 / CH10 | D5 |
| M3 | Middle_DIP | CH11 / CH12 | D6 |
| M2 | Middle_PIP | CH13 / CH14 | D7 |
| M1 | Middle_MCP | CH15 / CH16 | D8 |
| R3 | Ring_DIP | CH17 / CH18 | D9 |
| R2 | Ring_PIP | CH19 / CH20 | D10 |
| R1 | Ring_MCP | CH21 / CH22 | D11 |
| L3 | Little_DIP | CH23 / CH24 | D12 |
| L2 | Little_PIP | CH25 / CH26 | D13 |
| L1 | Little_MCP | CH27 / CH28 | D14 |

`Thumb_CMC` 用于维持拇指根部结构，不计入 14 路检测输出。`Sensor_01` 至 `Sensor_14` 按上表顺序一一对应。

## 最终导出

- 网页模型：`public/models/hsad/hsad_complete_hand.glb`
- 可编辑中间文件：`tools/blender/reports/hsad_complete_hand_working.blend`
- 机器报告：`tools/blender/reports/merge_report.json`
- 文件大小：422,104 bytes（约 412.2 KiB）
- 三角面数：42,990
- 骨骼数：16，其中 14 根输出关节骨骼
- 压缩：Draco level 6

“认识装置”和“关节信号与动作映射实验台”加载同一 GLB；网页端以四元数插值驱动关节和根姿态。
