# 3D 手模型实现说明

## 实现结论

项目未找到论文原始 Blender、FBX、GLB 或其他可编辑手模型。当前采用 React Three Fiber + Three.js，以论文图 3-8、3-9、3-10 和用户提供的黄色简化手势参考图为依据，程序化复刻一只统一的金黄色实体教学手。

## 模型体系

- 文件：`src/components/hand3d/UnifiedHand3D.tsx`。
- 单一组件提供 `device`、`virtual`、`gesture` 三种表现变体。
- 手掌、腕部和各指节由 Three.js 几何体构成；指节由嵌套关节组形成骨骼层级。
- 拇指 2 个可动关节，其余四指各 3 个，共 14 个。
- 每个可动节段参与 R3F raycaster 点选；当前关节以蓝青高亮和橙红关节点反馈。
- 根节点接收 Pitch、Yaw、Roll，局部节点接收 14 个关节角。
- `useFrame` 与 `THREE.MathUtils.damp` 进行连续阻尼插值，避免折断感和瞬移。
- 装置页使用 OrbitControls 等价控制器，支持环绕、缩放与轻度平移。

## 视觉一致性

- 主体采用金黄 / 黄褐色，来自论文简化手势图的教学示意色，而不是青色全息线框。
- 表面平滑、低金属度、适中粗糙度；不使用写实皮肤、机械骨架或医学解剖外观。
- `device` 变体在同一手上增加橙色 FPC 教学层和深蓝手背模块，保持装置与虚拟映射之间的视觉亲缘。
- 该模型是“代码化教学复刻”，不是论文截图，也不冒充真实装置照片。

## 14 关节接口

数据键为 `T1/T2`、`I1/I2/I3`、`M1/M2/M3`、`R1/R2/R3`、`L1/L2/L3`。页面展示名称与真实通道顺序由 `jointHotspots.ts` 统一维护。模型只负责姿态，实验数据源可以从 mock 平滑替换成 CSV、串口或 WebSocket。

## 当前限制

1. 论文未提供原始骨骼约束和逐关节旋转轴，当前轴向根据论文示意和手部屈曲关系复刻。
2. 字母手势中的外展、交叉、指尖接触需要更多自由度；当前仅做教学预设，不作为 37 类真实标准动作。
3. 若后续取得原始 Blender/GLB，应保留现有数据接口，替换渲染层并完成每个关节的 0–90° 标定。
