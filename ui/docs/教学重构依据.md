## 3. 关节与通道校正

Python 程序读取 31 个字段：前 28 个为压电原始通道，最后 3 个为 Pitch、Yaw、Roll。两路原始信号以 `(V+ - V-) / 2` 得到一路有效信号，共 14 路。程序中的有效通道顺序是：

1. 拇指 IP；2. 拇指 MCP；3–5. 食指 DIP/PIP/MCP；6–8. 中指 DIP/PIP/MCP；9–11. 无名指 DIP/PIP/MCP；12–14. 小指 DIP/PIP/MCP。

本轮已按此顺序重写 `src/data/jointHotspots.ts`，避免旧版页面把近端到远端简单顺排所造成的通道错位。

## 4. EDA 与程序带来的边界

- 柔性板工程确认了手形 FPC、14 个检测位置与蛇形柔性连接区。
- 硬板原理图确认了 ESP32-WROOM-32E、TMUX1574 模拟多路复用、JY60 IMU、电源/充电和信号调理相关模块。
- 程序配置提供 80 Hz 采样与 6 Hz 二阶低通处理依据。
- 网页三维硬件只用于“器件在系统中的作用”教学，不复刻精确 PCB 走线，也不作为 EDA 工程图。
