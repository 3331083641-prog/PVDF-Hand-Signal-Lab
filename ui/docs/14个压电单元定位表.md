## 几何和绑定契约

每个压片都满足以下建模契约：

1. 薄圆角矩形，长轴沿对应手指骨链。
2. 中心位于关节旋转轴，网格跨过近侧与远侧骨端。
3. 近端权重分配给近侧骨，远端权重分配给远侧骨，中间平滑过渡。
4. MCP 近端由手背 `MainFPC` 连入；PIP/DIP 由前一压片端部的蛇形段连入。
5. 小指压片宽度单独缩小；拇指使用独立斜向几何，未复制四指姿态。
6. 点击选择使用 `Highlight_*`，相机聚焦优先使用 `*_Sensor` 解剖别名节点，信号数据使用同一 `shortId`。

## 代码同步位置

- 统一元数据：`src/data/jointHotspots.ts`
- 三维模型解析/高亮：`src/components/hand3d/HSADHand3D.tsx`
- 认识装置：使用同一 `sensorMetadata` 与模型节点。
- 信号与动作映射实验台：`shortId` 同时控制骨骼、当前通道、差分波形和结果区。

导出对象 `jointChannelMap`、`modelNodeMap`、`sensorMetadata` 均由同一 14 项数据派生，避免多份映射产生漂移。
