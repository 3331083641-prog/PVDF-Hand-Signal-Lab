## 2. 论文与程序事实

- 装置使用柔性 PVDF 压电传感器，共 14 个关节检测单元：拇指 2 个，其余四指各 3 个。
- 每个检测单元提供一对原始电压，共 28 路；有效信号为 `Udiff(t) = [Vplus(t) - Vminus(t)] / 2`，共 14 路。
- 上位机输入帧为 31 个数：28 路原始电压与 Pitch、Yaw、Roll。
- 目标采样率为 80 Hz；原始电压显示范围为 0–3.3 V，静态基线约 1.65 V；差分信号以 0 V 为基线，范围约 −1.65–1.65 V。
- 程序包含零点校准、安静状态慢漂移跟踪、约 0.006 V 的小信号积分阈值、二阶 6 Hz 低通滤波、梯形积分与 0–90° 限幅。
- 伸展阶段使用论文式保持时间修正：`1.056 - 0.11·exp(-t/2.3374)`。
- 角度输出为 14 个关节角，姿态输出为 Pitch、Yaw、Roll。

## 3. 本轮采用的公式

1. 双通道差分：`Udiff(t) = [Vplus(t) - Vminus(t)] / 2`。
2. 教学反推关系：`Uideal(t) ≈ (1/Cj)·dθ(t)/dt`。
3. SIA 角度：`θ(t) = Cj∫Udiff(t)dt`，数值实现使用梯形积分。
4. 保持时间修正：`correction(t) = 1.056 - 0.11·exp(-t/2.3374)`。
5. 正压电效应的简化本构表达：`D = dT + εE`。
