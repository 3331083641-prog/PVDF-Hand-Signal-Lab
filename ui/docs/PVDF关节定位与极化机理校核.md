## 2. 解剖位置与模型绑定

定位原则是“压片中心对准关节旋转轴，并跨越关节两侧”，而不是放在某一节指骨中央。

- 拇指：`Thumb_IP_Sensor` 跨越近节/远节指骨之间的 IP；`Thumb_MCP_Sensor` 跨越掌部与近节指骨之间的 MCP。两片长轴独立沿拇指斜向骨链布置。
- 食指、中指、无名指、小指：每指的 DIP、PIP、MCP 分别跨越远端指间、近端指间和掌指关节。
- 每个压片网格同时使用近侧骨与远侧骨权重；中部平滑过渡，避免作为刚性芯片只随一节骨整体旋转。
- `Highlight_*` 和解剖别名节点放在同一关节轴，网页聚焦与点击优先使用这些节点。
- 手背主板和芯片保持刚性；柔性压片、指部 FPC 与蛇形段随骨骼变形。

完整通道与节点表见 [14个压电单元定位表.md](./14个压电单元定位表.md)。

## 3. 蛇形 FPC 连续性

模型中每根路径均为结构连续链：

- 四指：`MainFPC → MCP 压片 → 蛇形段 → PIP 压片 → 蛇形段 → DIP 压片`。
- 拇指：`MainFPC → Thumb MCP 压片 → 蛇形段 → Thumb IP 压片`。

走线从压片端部引出，不穿过压片中央。验证脚本在 0°、30°、60°、90° 下检查传感器、FPC 与蛇形段的接触/邻近关系；主板不参与手指形变。

## 4. 极化、应力与输出符号约定

### 4.1 物理事实

PVDF 在极化后具有有序偶极。机械应力改变极化状态和电位移，电极上的自由电荷随之重新分布；动画不把它表现成正负离子在 PVDF 体内自由迁移。

采用正压电本构：

\[
D_3=d_{31}T_1+\varepsilon_{33}^{T}E_3
\]

在电荷放大器输入近似虚地的教学条件下：

\[
D_3\approx d_{31}T_1,\qquad Q=\int_A \mathbf D\cdot \mathbf n\,\mathrm dA
\]

论文第 3.3 节说明上下两层在弯曲时产生大小相近、方向相反的响应；终端使用两路差分增强目标弯曲并抑制共模扰动：

\[
V_+(t)=+S(t)+N_c(t)+n_+(t)
\]

\[
V_-(t)=-S(t)+N_c(t)+n_-(t)
\]

\[
U_{diff}(t)=\frac{V_+(t)-V_-(t)}{2}
\]

### 4.2 本页面的符号定义

为保证动画、接线和波形自洽，代码明确约定：

- “正向弯曲”：结构向页面上方形成正曲率；上层显示拉伸、下层显示压缩。
- 在默认极化方向下，正向弯曲令 `V+` 上升、`V−` 下降，`Udiff` 为正；反向弯曲全部反号。
- 翻转“极化方向”只反转界面电荷与输出符号，不改变几何弯曲方向。
- 橙红 `+` 与蓝青 `−` 只出现在 PVDF/电极界面附近，密度代表可测动态自由电荷指示，不代表材料内部永久离子数。

该绝对正负号是结合本网页的通道命名形成的教学约定；真实硬件若交换电极或放大器输入，绝对符号可整体反转，但上下通道相反、反向运动反号以及差分增强关系不变。

## 5. 五个动态阶段

| 阶段 | 几何/应力 | 界面自由电荷 | 终端差分信号 |
|---|---|---|---|
| 静止 | 平直或初始曲率；保留低透明度极化箭头 | 近似平衡，仅弱屏蔽电荷 | 0 V 附近 |
| 正向弯曲 | 上拉伸、下压缩 | 上下界面呈相反符号，密度随应力和速度增大 | 正向瞬态 |
| 反向弯曲 | 上压缩、下拉伸 | 所有界面符号同步反转 | 负向瞬态 |
| 保持 | 几何仍保持弯曲 | 可测动态电荷指示因反馈、泄漏与弛豫降低；极化箭头不消失 | 衰减回基线 |
| 释放/伸展 | 曲率减小，应力变化方向反转 | 相对弯曲阶段重新分布 | 与进入弯曲时相反的脉冲，最终回到 0 V |

## 6. 论文事实与教学简化边界

论文事实包括：14 个关节位置、双层 PVDF 反向响应、差分关系、弯曲/伸展反号、保持阶段动态端口信号衰减以及积分获得关节角的主链路。

教学简化包括：

- 七层厚度和电荷粒子数量不按真实微米尺度绘制；粒子是符号化可视标记。
- 应力颜色和箭头表达拉伸/压缩方向，不是 COMSOL 定量场结果。
- 页面波形来自与实验台共用的 80 Hz 可复现教学推演引擎，不冒充论文实测曲线。
- 绝对正负号以代码中的 `V+ / V−` 接线约定为准；真实硬件校准数据接入后可配置替换。
