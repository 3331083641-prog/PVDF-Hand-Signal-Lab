# GPT image2 生图清单与提示词

> 版本：第一阶段视觉资产决策。本文只定义素材与提示词，不生成图片；AI 图均为“科研概念视觉”，不得被表述为实验实物或实验结果。

## 1. 项目视觉目标

本项目是“基于柔性 PVDF 压电传感器的手部动作信号采集装置”教学型交互系统，面向本科生、研究生、答辩/竞赛评委及科技馆式教学展示观众。系统要把一条真实的物理链路讲清楚：**手指弯曲 → PVDF 形变 → 压电电荷产生 → 电荷放大 → 差分处理 → 数字滤波 → 信号积分 → 关节角映射**；最终支持 37 类固定手势识别，以及 14 个关节角度与 Pitch、Yaw、Roll 的实时映射。

图片的职责不是代替数据或电路图，而是承担三件事：让观众先看见真实装置、让不可直接看见的压电与信号处理过程可理解、让“真实手—虚拟映射”的教学结果有清晰的空间想象。整套视觉应服务于“观察装置—理解材料—操作采集—解释数据—完成映射”的教学链路。

## 2. 统一视觉规范

- **主色**：科研深蓝 `#123B5D`；用于坐标、说明和局部结构阴影。
- **辅助色**：数据蓝青 `#1BA9B8`、浅青 `#BDEFF4`；用于信号、箭头、透明层。
- **强调色**：装置识别色为橙黄色柔性 FPC `#D88314` 至 `#F0A321`；少量橙红 `#E85B35` 只用于关键节点或受力强调。
- **背景色**：白色或极浅灰 `#F5F7F8`；必须保留整洁、可读的网页叠加空间。
- **风格关键词**：高校科研教学、前沿物理、科技馆交互展项、专业、克制、清晰、真实器件优先。
- **光影**：柔和棚拍/展项漫反射光，弱阴影，局部蓝青数据辉光；不使用黑底霓虹、镜面反射或过饱和光轨。
- **材质**：PVDF 单元表现为半透明琥珀色薄膜；FPC 为真实橙黄柔性电路；真实 PCB/器件只可从参考图忠实保留。
- **科研与教学平衡**：每张图最多呈现一个关键概念，留给正文、SVG 和交互解释的空间；不要做“好看但不能讲课”的背景。
- **文字**：生成图中原则上不出现中文、英文标签、数字或公式；所有文字、编号、箭头说明由网页 HTML/SVG 后加，防止乱码与错误术语。
- **透明背景**：仅对可叠加的 PVDF 单元、结构局部或映射概念主体建议透明背景；主视觉/教学场景使用浅灰或白背景。
- **网页叠加空间**：横幅图至少留出 35% 干净留白；不要将重要器件放到左上标题区或右下按钮区。
- **禁止元素**：普通布质电子手套、机械外骨骼、虚构医疗诊断、悬浮芯片、错误手指数量、额外 LED、乱码、赛博朋克城市、通用 SaaS 插画、虚假实验室照片。

- [ ] 是否遵守白灰背景、蓝青数据、橙黄 FPC、少量橙红强调的统一配色。
- [ ] 是否无乱码、错误中文、内嵌 UI、logo 或未经证实的性能数字。
- [ ] 学生能否从图中说出一个明确物理知识点、一个可操作对象或一条信号链路。
- [ ] 该图是否会让评委把 AI 概念图误以为真实实验实物；若可能，是否已提供图注和替代文本。
