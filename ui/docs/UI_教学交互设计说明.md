# UI教学交互设计说明

## 用户旅程

看见真实装置 → 理解PVDF形变与电荷 → 在实验室操作差分、滤波与积分 → 用关节角和姿态控制虚拟手 → 在37类手势任务中完成教学演示与复盘。

## 信息架构

- `/` 首页与教学导览
- `/device` 认识装置与14个热点
- `/physics` PVDF物理机理与教学模拟
- `/lab` 信号处理实验室
- `/mapping` 实时映射控制台
- `/gestures` 37类固定手势任务
- `/summary` 竞赛亮点与项目总结

首页保留连续教学主线，实验室、映射、手势任务通过哈希路由进入独立工作区。教师可按顺序演示，学生可从任何步骤进入并返回学习链。
